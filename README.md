# IT-Procurement-Automation

**Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer**

Platform: ServiceNow | SmartBridge / SkillWallet Project

## Project Overview
This project aims to simplify the ordering of standard laptops through the ServiceNow Service Catalog and to automate request processing with Flow Designer.

## Objectives
- Provide one catalog item for ordering a standard laptop.
- Allow employees to select optional software.
- Automate request processing with Flow Designer.
- Keep request status clear and reduce manual work.

## Verified Configuration
- Catalog item: Standard Laptop (Lenovo - Carbon x1), Active
- Category: Hardware (Service Catalog)
- Specifications: Intel Core i5, 512GB SSD, backlit keyboard
- Optional software: Adobe Acrobat, Adobe Photoshop
- Additional field: Additional software requirements

## Proposed Automation (Not Yet Verified)
Flow Designer flow triggered by a Standard Laptop request, with approval logic, fulfilment task creation, status updates and error handling.

## Technologies
ServiceNow, Service Catalog, Flow Designer
